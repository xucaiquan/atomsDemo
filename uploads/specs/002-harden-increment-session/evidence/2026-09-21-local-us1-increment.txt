6. T014 产物级核对（e2e_two_round.py）
============================================================

改造前的缺口（已实测确认，不是推测）：A5 的三条结论
（长度比、旧功能保留 kept、新增「历史」added_history）**只 log 不判定**，
退出码只看 results.get("round2") != "failed"。用旧实现跑同一场景：

  旧实现退出码（第二轮成功，但 + 和 AC 都从产物里消失了）: 0

也就是说：第二轮把第一轮功能全部丢掉，探针照样 exit 0 —— 恰恰是 A5 该拦的
场景它拦不住。此外旧的功能探针用裸子串（"-" in html、"." in html），而任何
HTML 都含 `-`（<!DOCTYPE html>）、`.`、`/`（闭合标签），判定恒为真，等于空转。

本次改造：
  * 新增 buttons(html)：从 <button> 可见文本提取控件集合；
  * 新增 ARITH_BUTTONS：计算器算子控件集合（+ - × * ÷ / = . AC C ± %）；
  * 新增 check(failures, label, ok, detail)：日志可见 + 失败影响退出码；
  * _dump(results, failures)：任一条失败即非零退出。

现在逐项判定（全部为产物级，均不看「注入了什么」）：
  ① A5 长度比 seq2/seq1 >= 0.80
  ② A5 第一轮确实产出了可识别的算子按钮（>= 4 个，防「两边都空所以都没丢」）
  ③ A5 旧功能保留：第一轮的算子按钮集合 ⊆ 第二轮按钮集合，列出丢失项
  ④ A5 新增能力「历史」出现在第二轮产物
  ⑤ A7 每版 html_sha256 与 html 自洽
  ⑥ A7 每版以 </html> 结尾
  ⑦ A7 每版恰好一个 <body> 与一个 <!DOCTYPE>（防拼接双文档/缺骨架）
  ⑧ A7 第二轮后回取 v1 摘要未变
  ⑨ A7 第二轮后回取 v1 html **逐字节**不变
  ⑩ 隔离：新身份的项目列表不含本探针项目
  ⑪ 隔离：新身份直接取本项目详情返回 404
  ⑫ 新会话（仅 header）能取回两轮版本，且 v2 摘要一致

离线校验（不调用线上，不消耗配额）：
  * buttons() 区分得开——删掉 <button>-</button> 与 <button>/</button> 后
    lost set = ['-', '/']（非空），而正文里的 `-` `.` `/` 不会被误抓；
  * 退出码判定——无失败 exit 0；有失败 exit 1；轮次 1 超时 exit 1
    （旧实现在轮次 1 TIMEOUT 时同样 exit 0，一并修正）；
    「第二轮成功但丢功能」exit 1。
